# WhatsApp Desktop UI Clone

A full-viewport, responsive WhatsApp-inspired interface built with React, JSX, CSS, Vite, and Lucide icons.

## Run the project
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Features
- Full-browser-viewport desktop layout with a left navigation rail
- Chat list and responsive mobile view
- Search and All, Unread, Favorites, Groups filters
- Sample conversations and local message sending
- Contact details, menu popovers, favorite toggle, and demo notifications

## Notes
This is a front-end demo, not the official WhatsApp application. Messages are stored in React state and reset when you refresh. It does not connect to WhatsApp or support real accounts, calls, end-to-end encryption, or cross-user messaging. Those features require a backend, database, authentication, and a real-time messaging layer.
